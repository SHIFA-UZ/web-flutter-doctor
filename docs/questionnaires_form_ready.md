## Doctor Questionnaire (Form-ready)

### Form description
Anonymous academic questionnaire for evaluating the Shifa doctor app prototype.  
Estimated completion time: 8-12 minutes.

### Questions

1. **Consent to participate**  
   Type: Multiple choice (required)  
   Options: Yes / No

2. **Your primary role**  
   Type: Multiple choice  
   Options: Physician / Resident physician / Administrator or operational staff / Other

3. **How often have you used the doctor app in the last 2 weeks?**  
   Type: Multiple choice  
   Options: Daily / Several times per week / About once per week / Less than once per week / Not used in the last 2 weeks

4. **Main device used for the doctor app**  
   Type: Multiple choice  
   Options: Desktop or laptop / Tablet / Smartphone browser / Mixed devices

5. **Main workflows you used most**  
   Type: Checkbox (max 3 selections)  
   Options: Calendar or schedule management / Appointment handling / Patient list or patient context / Messaging or communication / Documents / Video consultation flow / Tasks or notifications

6-15. **SUS items (10 questions)**  
   Type: Linear scale (1-5)  
   Anchors: 1 = Strongly disagree, 5 = Strongly agree  
   Items:
   - I think that I would like to use this system frequently.
   - I found the system unnecessarily complex.
   - I thought the system was easy to use.
   - I think that I would need support from a technical person to use this system.
   - I found the various functions in this system were well integrated.
   - I thought there was too much inconsistency in this system.
   - I would imagine that most people would learn to use this system very quickly.
   - I found the system very cumbersome to use.
   - I felt very confident using the system.
   - I needed to learn a lot of things before I could get going with this system.

16. **The app supports appointment and schedule coordination without unnecessary manual work.**  
   Type: Linear scale (1-5)

17. **The messaging flow in the app is more suitable for clinical follow-up than informal channels (e.g., Telegram/phone).**  
   Type: Linear scale (1-5)

18. **Patient context (appointments, messages, documents, tasks) is sufficiently connected for day-to-day work.**  
   Type: Linear scale (1-5)

19. **The app responds fast enough for routine clinical/administrative tasks (perceived performance).**  
   Type: Linear scale (1-5)

20. **During my use, the app was sufficiently stable and available for the tasks I needed (perceived availability).**  
   Type: Linear scale (1-5)

21. **Which area currently needs the most improvement?**  
   Type: Multiple choice  
   Options: Scheduling or calendar logic / Messaging or communication flow / Documents or records workflow / Video consultation workflow / Tasks or notifications / Overall speed or stability

22. **What was the most useful part of the doctor app for your work, and why?**  
   Type: Paragraph

23. **What is the single most important improvement you would request before wider rollout?**  
   Type: Paragraph
