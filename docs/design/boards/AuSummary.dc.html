What changed in this pass

  • Tokens: every colour, font size, line height, size, radius, shadow, blur and tracking value in the prototype is a DS token. New families: font-size, line-height, letter-spacing, blur, basis (reflow widths) and layout widths.
  • Components: 3 new shared components (Pressable, OptionList, ActionBar) and one dialog surface (.sh-sheet) replaced about 150 hand-painted buttons, 8 option lists, 4 footer styles and 10 dialog shells.
  • Usability: 44px touch targets on phone, AA contrast for all text except white labels on the teal primary (teal-50, restored as the patient-app primary in Nov 2026), no text under 10px, one place for Save, calmer web calendar.
  • Both apps: the shared set (Button, IconButton, ActionButton, Chip, StatusBadge, InputField, Dropdown, SearchField, ChatBar, ChatBubble, NavBar, Tray, Toast, Pressable, OptionList, ActionBar) is documented for the patient app too.
  • Tested: 11 flow scripts pass on web and phone; 20 screens at 1440 / 1024 / 768 / 390 / phone with no overflow or clipping; the usability sweep reports 0 issues; DS previews checked at their card widths.
