**Answers (round 1, all fixed; round 2 run because the gesture handling and the lifecycle changed):**
1. *Requesting access blocks reopening:* fixed; the screen releases its ViewModel's state when it leaves (`release()`), so the request flag is forgotten and opening again loads afresh. Tested.
2. *Closed viewers keep their files:* fixed by the same release: leaving the screen drops the bytes (the shell keeps the ViewModel object, not the file). Tested.
3. *Double tap never reaches a PDF:* fixed; the zoom modifier reads taps in its own gesture loop, ignoring what the page list consumed (one finger, no travel, two within the double-tap timeout).
4. *A broken PDF has no Retry:* fixed; Retry (download again) above Save to device.
