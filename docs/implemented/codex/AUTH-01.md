1. *Process recreation:* the top-level screen is no longer saveable, so a recreated process starts at the splash, which restores the session and re-runs the gate.
2. *Update re-check:* "Update" only opens the store; a `LifecycleResumeEffect` on the update frame re-checks when the app comes back.
3. *Skip:* a tap on the splash completes a `skipped` deferred, which ends the brand wait (the checks still finish). Covered by a test. The emulator also caught an init-order crash: the deferred was declared after `init`, which runs `check()` at once on `Main.immediate`. It now comes first, with a test on an immediate dispatcher.
4. *Boot frames at large text:* the boot frame scrolls, with a minimum height so it stays centred while it fits.
5. *`Result<T>`:* `bootGate` returns `Result<BootGate>`; the ViewModel maps a failure to "no gate".
