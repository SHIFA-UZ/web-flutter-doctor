Consequently, `403 {"code":"ACCOUNT_DISABLED"}` emits a logout event, contradicting the requested absolute “403 never does” rule. The new test explicitly requires this behavior.

- **P1 — Stored tokens reach public backend resources.** [ApiConfig.kt:25](/Users/sheroziy.saidkhodjaev/Projects/Private/shifa/web-kmp-doctor-app/composeApp/src/commonMain/kotlin/shifa/doctor/data/api/ApiConfig.kt:25) excludes only `auth/` and `public/`. An expired token also blocks these public requests and ends the session.

- **P2 — Language deduplication races across suspension and logout.** [LanguageRepository.kt:26](/Users/sheroziy.saidkhodjaev/Projects/Private/shifa/web-kmp-doctor-app/composeApp/src/commonMain/kotlin/shifa/doctor/data/settings/LanguageRepository.kt:26) checks `synced` before suspending, then updates it after completion. Concurrent identical calls both send; an old request completing after `reset()` repopulates the cache and can suppress the next account’s required sync. Serialize updates and invalidate completions from previous sessions.

- **P2 — Pre-flight reverses the documented grace period.** [Jwt.kt:25](/Users/sheroziy.saidkhodjaev/Projects/Private/shifa/web-kmp-doctor-app/composeApp/src/commonMain/kotlin/shifa/doctor/utils/Jwt.kt:25) expires tokens at `exp − 30 seconds`. Both architecture §3 and API reference §1 specify `exp + 30 seconds < now`; master-plan §1 says to retain that check. The implementation logs users out approximately 60 seconds earlier than that contract.

- **P2 — Malformed JWT claim types escape the decoder.** [Jwt.kt:15](/Users/sheroziy.saidkhodjaev/Projects/Private/shifa/web-kmp-doctor-app/composeApp/src/commonMain/kotlin/shifa/doctor/utils/Jwt.kt:15) accesses `jsonPrimitive` outside `claims()`’s exception handling. Payloads containing `"exp":{}` or `"role":[]` throw instead of returning unreadable claims. During pre-flight this becomes a misleading `NetworkError`, leaving the unusable token installed.

- **P2 — SSE dispatches incomplete events.** [Sse.kt:72](/Users/sheroziy.saidkhodjaev/Projects/Private/shifa/web-kmp-doctor-app/composeApp/src/commonMain/kotlin/shifa/doctor/data/api/Sse.kt:72) flushes at EOF, so a connection ending midway through `data:` delivers truncated content as a complete event. SSE requires discarding pending data unless a blank line terminates the event; the new EOF test encodes the opposite behavior. [SSE parsing specification](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation).
