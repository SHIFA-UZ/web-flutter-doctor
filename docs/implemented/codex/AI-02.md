Kotlin/Native 2.3.0’s `\s` matches only ASCII whitespace; [Dart uses ECMAScript regex semantics](https://api.dart.dev/dart-core/RegExp-class.html), including nonbreaking spaces. Consequently, `##\u00A0Plan` and `-\u00A0Follow-up` become plain paragraphs on iOS, and a >220-character answer with three sentences separated by `.\u00A0` stays unsplit. Flutter recognizes all three cases. Use an explicit Dart-compatible whitespace class and add these regression cases.
