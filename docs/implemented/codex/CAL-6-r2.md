**Answers (round 2, all fixed):**
1. *Reopening leaks ViewModels and timers:* the cache collector and the 30 s tick moved into `follow()`, which the screen runs while it is shown (`LaunchedEffect`); a closed panel's ViewModel left in the shell store holds neither. The ViewModel object itself stays until sign-out (small, inert; the shell has no per-route store yet).
2. *Removed appointment still actionable:* when the re-read day no longer has the appointment (and nothing of the panel's is running) the panel closes; when it turns cancelled the cancel question closes. Tested.
3. *Reschedule can't scroll:* the month and slots scroll inside the tray, Move stays below them; `ProfileSheet` now opens at full height (it stopped half way for tall trays). Checked on the emulator.
4. *Slots at one time lose locations:* every free slot is its own chip; the current time is added as its own greyed chip.
5. *Back drops duration edits:* Back (header and system, through `FormExitEffects`) asks with the shared Discard question when the picked length is unapplied. Tested.
6. *Reschedule leaves the panel open:* a successful move reads both days, closes the panel and the shell shows "Appointment moved". Tested.
